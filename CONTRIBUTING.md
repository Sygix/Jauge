# Contributing to Jauge

Thanks for your interest in Jauge.

## How to contribute

Contributions go through issues and discussions:

- **Bug reports and feature requests:** use [the issue forms](https://github.com/Sygix/Jauge/issues/new/choose). Please search the existing issues first.
- **Questions and ideas to discuss:** use [GitHub Discussions](https://github.com/Sygix/Jauge/discussions).
- **Security problems:** report them privately, see [SECURITY.md](SECURITY.md).

Never include personal data such as email addresses, account names, tokens, authorization codes or raw API responses in an issue, a discussion or a log excerpt.

## Pull requests

Pull requests are reserved for the repository collaborators. Pull requests from outside contributors are not reviewed or merged, so please do not send patches: open an issue or a discussion describing the problem or the idea instead.

## Translations

The app ships in English and French. Strings live in `app/src/main/res/values/strings.xml` (English) and `app/src/main/res/values-fr/strings.xml` (French). To suggest a new language, open a feature request.
